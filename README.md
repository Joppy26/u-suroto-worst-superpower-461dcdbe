An entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on make.fun: invent the most useless superpower in one line of at most 140 characters.

`main.ts` deterministically writes the one-line entry to `/output/entry.txt`. Pure Node, no dependencies, no network, no randomness, no clock.

Run it with:

```sh
node main.ts
```
